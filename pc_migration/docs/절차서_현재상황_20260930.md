## 1. 새 PC — 저장소 파일 받아 USB 에 담기 (지금)

### 1-1. USB 확인

```powershell
Get-Volume | Where-Object DriveType -eq 'Removable' | Format-Table DriveLetter, FileSystemType, FileSystemLabel, @{n='여유GB';e={[math]::Round($_.SizeRemaining/1GB,1)}}
```

- `FileSystemType` 이 **NTFS** 여야 한다. FAT32 는 4GB 넘는 파일을 못 담고, exFAT 은 권하지 않는다.
- NTFS 가 아니면: 탐색기 → USB 우클릭 → 포맷 → 파일 시스템 NTFS. **USB 안의 자료가 모두 지워진다.**
- 외장 SSD/HDD 는 `DriveType` 이 `Fixed` 로 나올 수 있다. 그때는 `Get-Volume` 만 치고 글자를 확인한다.
